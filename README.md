
# Real-Time Chat App

This project was created for practice and learning purposes to understand how **Next.js, Python FastAPI, and WebSocket** work together to build a real-time chat application.
Learning Goals

By completing this project, I practiced:

HTML/CSS UI development

Converting HTML into Next.js

React state management

useEffect

WebSocket connection

WebSocket send()

WebSocket onmessage

FastAPI

Python WebSocket server

Real-time client-server communication

Running frontend and backend separately
